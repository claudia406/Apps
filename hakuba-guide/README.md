# 白馬 母娘旅行 2026 — デジタルしおりアプリ

母娘2人の白馬2泊3日旅行専用デジタルしおりPWAアプリです。

## アプリ概要

「旅行前からワクワクし、旅行中もガイドブックとして使え、旅行後も思い出として残したくなる」をコンセプトにした、スマホ向け旅行しおりアプリです。

## 主な機能

| ページ | 内容 |
|--------|------|
| ホーム | 出発カウントダウン、宿泊先情報、今日のメッセージ |
| 旅程 | Day1/2/3 タイムライン形式の旅程 |
| グルメ | 全食事情報（営業時間・地図リンク付き） |
| スポット | 各観光スポットの詳細・雨天案・地図リンク |
| マップ | 全スポット一覧 & Google マップリンク |
| 持ち物 | タップでチェックできる荷物リスト |

## 旅行概要

- **日程**: 2026年8月7日（金）〜9日（日）
- **出発地**: 横浜
- **移動**: 新幹線・バス・タクシー・徒歩
- **1泊目**: 白馬龍神温泉 RYOKAN SUI（神城）
- **2泊目**: プチホテル アンシャンテ（白馬村）

## 技術構成

- HTML / CSS / JavaScript（単一ファイル、ライブラリなし）
- PWA（Progressive Web App）
- Service Worker によるオフラインキャッシュ
- localStorage による持ち物チェック状態の永続化

## 使用方法

### ブラウザで開く

`index.html` をブラウザで直接開くか、GitHub Pages のURLにアクセスしてください。

### ホーム画面に追加（PWA）

**iPhone / Safari の場合:**
1. Safari でアプリのURLを開く
2. 共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」をタップ
4. 名前を確認して「追加」をタップ

**Android / Chrome の場合:**
1. Chrome でアプリのURLを開く
2. メニュー（⋮）→「ホーム画面に追加」をタップ

### オフライン利用

一度ホーム画面に追加すると、機内モードでも全コンテンツが閲覧可能になります。

## 写真の差し替え方法

現在は CSS グラデーションのプレースホルダー画像を使用しています。
実際の写真に差し替える場合は、`index.html` 内の `.spot-img` 要素の中に `<img>` タグを追加してください。

```html
<!-- 変更前 -->
<div class="spot-img" style="background:linear-gradient(...)">🚡</div>

<!-- 変更後 -->
<div class="spot-img" style="overflow:hidden;padding:0">
  <img src="your-photo.jpg" alt="説明" style="width:100%;height:100%;object-fit:cover">
</div>
```

## 出発日の変更方法

`index.html` の JavaScript 内の以下の箇所を変更してください。

```javascript
const dep = new Date('2026-08-07T00:00:00');
```
