マナー・タブー

🚫
禁止（罰金あり）
  • ・ガム（輸入・所持・販売すべて禁止）
  • ・路上・公共エリアでの喫煙（指定場所のみ）
  • ・MRT・バス車内での飲食
  • ・ドリアンの持ち込み（MRT・タクシー等）
  • ・公共トイレの使用後の未フラッシュ
🕌
宗教施設のマナー
  • ・肌の露出を控える（肩・膝を隠す）
  • ・モスクは礼拝時間中は見学不可
  • ・ヒンドゥー寺院は靴を脱いで入場
  • ・写真撮影は施設のルールに従う

  • ・チップ文化は基本なし（高級ホテルは例外）
  • ・タクシーの後部座席でもシートベルト必須
  • ・深夜10:30以降のコンビニでのアルコール販売禁止
  • ・左手渡しは失礼とされる文化あり
LANGUAGE
🗣️ Singlish フレーズ集
シンガポール英語（Singlish）には独特の表現がたくさん。知っていると現地の人と仲良くなれる！
Lah / Leh / Lor
ラ / レ / ロ
語尾の感嘆詞・ニュアンス調整
「OK lah!」= いいよ！「Cannot lah」= ダメだよ。日本語の「ね」「よ」的な役割
Shiok!
シオック！
美味しい！最高！気持ちいい！
食事・天気・体験すべてに使える万能ポジティブ表現
Chope
チョープ
席を取り置きする
ティッシュパックをテーブルに置く＝席確保の合図
Alamak!
アラマッ！
あらまあ！Oh no！やれやれ！
驚き・困惑・軽い失敗に使う感嘆詞
Can / Cannot
キャン / キャンノッ
できる / できない
「Can or not?」= できる？「Can can!」= もちろん！
Makan
マカン（マレー語）
食べる
「Let's go makan!」= 食べに行こう！ホーカーでよく聞く
Bo jio
ボー・ジオ（福建語）
誘ってくれなかった（拗ねる表現）
SNSで使われる「一人で食べに行って bo jio！」= 誘わないで！
Wah lau!
ワーラオ！
なんてこった！マジか！
驚いたとき・ありえない場面に。「Wah lau, so expensive!」

好吃！
hǎo chī!（ハオチー！）
