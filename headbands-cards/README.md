# Headbands Activity – Word Cards

英語プログラム「Headbands Activity」で使用する単語カードシートです。

## アプリ概要

額に貼った単語カードを、ヒントをもとに当てるゲーム用の印刷素材です。
中学生・高校生向けに、学園祭・国際交流イベントでそのまま使えるクオリティで作成。

## 主な機能

- A4縦 × 9ページ構成（合計108枚）
- 1ページにつき12枚（3列×4行）
- 点線カットガイド付き（ハサミ・裁断機対応）
- Mochiy Pop One フォント（Google Fonts）
- パステル6色ローテーション背景
- 四隅デコ装飾（星・音符・花など）
- ブラウザで開いてそのまま印刷可能（@media print 対応）

## 使用方法

1. `index.html` をブラウザで開く
2. ブラウザの印刷機能（Ctrl+P / Cmd+P）を使用
3. 用紙サイズ：A4、余白：なし（またはデフォルト最小）
4. 印刷後、点線に沿ってカットして使用

## 技術構成

- HTML / CSS / Vanilla JavaScript（フレームワーク不使用）
- Google Fonts（Mochiy Pop One）
- 単一HTMLファイル
- JavaScript でカードを動的生成

## フォルダ構成

```
headbands-cards/
├── index.html   # 単語カードシート本体
└── README.md
```
