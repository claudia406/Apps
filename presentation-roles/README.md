# Presentation Role Scheduler

## アプリ概要

高校生向けサマープログラムで使用するプレゼンテーション役割自動割当アプリ。  
5〜20名の学生に対して、Presenter・Feedback Provider・Questioner の3役割をランダムかつ公平に割り当てる。

## 主な機能

- 学生数の選択（5〜20名）とスライダー操作による動的なフィールド生成
- 学生名の手動入力
- 事前割り当て（Preferred Assignments）の設定
- バリデーション付きスケジュール生成（制約違反の場合はエラー表示）
- Regenerate ボタンによる再ランダム生成
- Reset All ボタンで全設定初期化
- 夏をテーマにしたデザイン（レスポンシブ対応）

## 使用方法

1. スライダーで学生数（5〜20）を選択する
2. 各学生の名前を入力する（省略可：「Student N」が使われる）
3. 必要に応じて「Add Preference」で事前割り当てを設定する
4. 「Generate Schedule」をクリックしてスケジュールを生成する
5. 別のランダム配置が必要な場合は「Regenerate」をクリックする

## アルゴリズム概要

**制約:**
- 各ラウンドで3役割は異なる学生が担当
- 各学生が各役割をちょうど1回担当

**手法: ランダム化バックトラッキング**
1. 事前割り当て（Preferred Assignments）を適用し、矛盾をチェック
2. 残りのスロットを役割ごと（Presenter → Feedback → Questioner）に順次埋める
3. 各役割の未割り当て学生をシャッフルし、ラウンド制約を満たすよう再帰的に割り当て
4. 失敗した場合は最大400回リトライ
