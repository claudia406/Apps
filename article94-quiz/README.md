# 民法94条 第三者判定ゲーム

行政書士試験対策用スマホ専用Webアプリ。通謀虚偽表示（民法94条）における「第三者」の該当性をゲーム形式で学習できます。

## アプリ概要

「第三者にあたるか／あたらないか」を2択で回答し、ヒント図解・解説を通じて第三者該当性の判断基準を身につけることを目的とするクイズアプリです。

## 主な機能

- 全12問をランダム出題
- ヒント機能（棒人間・矢印・アイコンを使った状況図解）
- 正解・不正解のランダム演出＋アニメーション
- 各問題に解説（行政書士受験生向け）
- 結果画面（正答数・正答率・評価コメント）
- オフライン動作対応

## 使用方法

1. `index.html` をブラウザで開く
2. 「スタート」ボタンをタップ
3. 問題文を読み、必要に応じて「ヒントを見る」をタップ
4. 「第三者にあたる」または「第三者にあたらない」を選択
5. 演出確認後「解説を見る」で詳細確認
6. 「次の問題へ」で進む
7. 全12問終了後に結果を確認

## 技術構成

- HTML / CSS / JavaScript（単一ファイル）
- 外部ライブラリなし
- インストール不要・オフライン動作可能

## フォルダ構成

```
article94-quiz/
└── index.html   # アプリ本体（全機能を1ファイルに集約）
```

| ⑤ | 仮装譲受人の一般債権者 | 第三者にあたらない |
| ⑥ | 代理人が虚偽表示した場合の本人 | 第三者にあたらない |
| ⑦ | 仮装譲渡債権の債務者 | 第三者にあたらない |
