# マレーシア大学進学パスウェイプログラム

JAAC日米学術センター × ELC Malaysia のパスウェイプログラム向け営業資料（パンフレット）。

## アプリ概要

高校生・保護者を対象とした、マレーシア大学進学プログラムのデジタルパンフレット。
「見た瞬間に興味を持つ」スタイリッシュなデザインで、コストパフォーマンス・世界レベルの大学・充実したサポートを訴求する。

## 主な機能

- ヒーローセクション：コスト比較数字を大きく提示
- Why Malaysia：視覚的な費用比較バーチャート
- 進学先大学8選：カード形式で一目比較
- 費用シミュレーション：モデルケースと国際比較
- 進学フロー：5ステップのタイムライン
- 参加条件・お問い合わせ

## 使用方法

`index.html` をブラウザで開くだけで閲覧可能。印刷にも対応（@media print 設定済み）。

## 技術構成

- HTML5 / CSS3（単一ファイル）
- Google Fonts（Noto Sans JP / Montserrat）
- CSS Grid / Flexbox
- レスポンシブ対応（モバイル・タブレット・PC）

## フォルダ構成

```
malaysia-pathway/
  index.html   # パンフレット本体（単一ファイル）
  README.md
```
